Privacy Policy

Last updated: 20 November 2026

This policy describes how Restwavee Studio uses Google account authorisation for its owner-operated YouTube publishing workflow.

Information accessed

With the Google account owner's permission, the tool accesses YouTube account and channel identification information, video upload and processing status, and video metadata (including duration and privacy status). It also uses OAuth credentials to authenticate API requests. The tool does not request passwords.

How information is used

Access is used to verify the correct YouTube channel, upload videos privately, and check that uploaded videos are processed with the expected duration. The workflow is not offered as a public sign-in service.

Storage and security

OAuth credentials are stored as encrypted GitHub Actions repository secrets for the private publishing repository. The upload workflow temporarily processes video files and creates upload-verification reports. These reports may contain video IDs and status information, but should not contain OAuth tokens. Credentials are not intentionally published on this website.

Sharing

Information is transmitted to Google and YouTube as necessary to use their APIs, and processed by GitHub Actions to operate the workflow. Restwavee Studio does not sell Google user data or use it for advertising.

Retention and deletion

OAuth credentials remain in the repository's secret storage until replaced or deleted by the operator. Workflow logs and artifacts are retained according to GitHub's configured retention settings. The operator may remove credentials and associated workflow artifacts through GitHub.

Revoke access

The account owner can revoke the app's Google access at Google Account Connections. They can also delete the OAuth secret from GitHub Actions. Revoking access prevents future authorised uploads until the account is reauthorised.

Google API Services

This tool uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service and Google Privacy Policy.
